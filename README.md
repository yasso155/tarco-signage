# Tarco Signage — شاشات العرض + لوحة الأدمن

صفحتين:
- **الشاشة** `https://<الدومين>/?screen=jeddah` — تفتحها في متصفح الشاشة (fullscreen) وتشتغل لوحدها.
- **الأدمن** `https://<الدومين>/admin.html` — تضيف/ترتب البوستات، تعدل الفوتر والـQR، وتشوف حالة الشاشات.

أي تعديل في الأدمن يظهر في كل الشاشات خلال ثواني (Firestore realtime).

---

## التشغيل لأول مرة (حوالي 15 دقيقة)

### 1) مشروع Firebase
1. https://console.firebase.google.com → **Add project**.
2. **Build → Firestore Database → Create database** (Production mode، أي منطقة).
3. **Build → Authentication → Get started → Email/Password → Enable**.
   ثم تبويب **Users → Add user**: أنشئ إيميل وباسورد الأدمن.
4. **Build → Hosting → Get started**.
4b. **Build → Storage → Get started** (للفيديوهات؛ يحتاج خطة Blaze مع تنبيه ميزانية). الصور لا تحتاجه.
5. **Project settings → Your apps → (</>) Web app** → سجّل التطبيق وانسخ `firebaseConfig`.

### 2) الإعدادات في الملفات
- افتح `public/firebase-config.js` والصق القيم مكان `PASTE_...`.
- افتح `.firebaserc` وبدّل `PASTE_PROJECT_ID` باسم مشروعك.

### 3) النشر
```
npm i -g firebase-tools
firebase login
firebase deploy
```
(ينشر الصفحات + قواعد الأمان `firestore.rules`.)

### 4) تفعيل حساب الأدمن (مرة واحدة)
1. افتح `https://<مشروعك>.web.app/admin.html` وسجّل دخول بإيميل الأدمن.
2. ستظهر رسالة فيها **UID** — انسخه.
3. في Firebase Console → Firestore → **Start collection** باسم `admins` → Document ID = الـUID (أي حقل، مثلاً `ok: true`).
4. حدّث الصفحة — صارت لوحة الأدمن تفتح.

> الأمان: أي شخص يقدر يقرأ البوستات (الشاشات عامة)، لكن الكتابة فقط لمن له مستند في `admins`. عطّل التسجيل الذاتي (لا تضيف أي واجهة signup؛ المستخدمين تنشئهم من الكونسول فقط).

## الفيديو
- من الأدمن ارفع ملفات **MP4 (H.264)** أو WebM مثل الصور (نفس مربع الرفع). الأفضل عمودي (portrait) 1080×1920 أو أفقي 1920×1080، أقل من ~50MB للفيديو (الحد الأقصى 200MB).
- الفيديو العمودي يُعرض كاملاً بارتفاع حتى 1000px وسط الشاشة والخلفية مموّهة من جانبيه، والأفقي بعرض الكارد؛ ومن الأدمن تقدر تختار لكل فيديو «ملء الكارد» (يُقص إلى مربع). **بدون صوت**، ويبدأ مع دوره وينتقل للتالي عند نهايته. لو حددت «المدة» أطول من الفيديو يعيد نفسه، وأقصر يُقطع.
- الصورة المصغّرة (poster) تُلتقط تلقائياً من الفيديو وتُستخدم للخلفية المموّهة.
- تخصيص الفروع والتواريخ والتفعيل يعمل للفيديو مثل الصور. حذف البوست يحذف الملف من Storage.
- `firebase deploy` ينشر أيضاً `storage.rules` (القراءة عامة، الرفع/الحذف للأدمن). أول مرة قد يطلب منك Firebase صلاحية للربط بين Storage وFirestore — اقبلها (Y).
- مهم: الفيديو يُحمَّل مرة ثم يُخزَّن في كاش المتصفح؛ ضغط الفيديو (bitrate حوالي 4-6 Mbps) يخفف النقل والتحميل على أجهزة الأندرويد.

## روابط الشاشات

| الفرع | الرابط |
|---|---|
| الرياض | `/?screen=riyadh` |
| جدة | `/?screen=jeddah` |
| الدمام | `/?screen=dammam` |
| المدينة | `/?screen=madinah` |
| أبها | `/?screen=abha` |
| تبوك | `/?screen=tabuk` |
| القصيم | `/?screen=qassim` |

- لو الشاشة مركّبة بالعرض في نظام التشغيل وأنت عايز تدوّر الصورة: أضف `&rotate=90` (أو `270`).
- الفروع تتعدل/تنضاف من الأدمن → تبويب **الشاشات والفروع** (الـID بالإنجليزي صغير، وهو الذي يُستخدم في الرابط).
- كل بوست تقدر تخصصه لفروع معينة، وإذا ما اخترت فرع يظهر في الكل. وتقدر تحدد تاريخ بداية/نهاية.

## تشغيل الشاشة (Kiosk)
- Chrome على Windows:
  `chrome.exe --kiosk --autoplay-policy=no-user-gesture-required "https://<دومينك>/?screen=jeddah"`
  وضعه في Startup ليفتح مع التشغيل.
- أو أي تطبيق Kiosk مثل Fully Kiosk Browser (أندرويد).
- الضغط مرة على الصفحة يدخل fullscreen لو ما استخدمت `--kiosk`.
- الصفحة تمنع إطفاء الشاشة (Wake Lock) وتعيد تحميل نفسها كل 6 ساعات، وتكمل بآخر نسخة محفوظة لو الإنترنت انقطع.

## تجربة محلية
Firebase modules تحتاج http (مو file://):
```
cd public
python -m http.server 8000
```
ثم افتح `http://localhost:8000/?screen=jeddah`.
ما دامت قيم `PASTE_...` موجودة، الصفحة تشتغل في **وضع DEMO** بـ4 بوستات تجريبية.

## ملاحظات وحدود
- الصور تتخزن داخل Firestore (base64) بعد ضغطها تلقائياً (حتى 1200px JPEG) لتبقى أقل من حد المستند (~1MB) — فلا تحتاج Storage ولا خطة Blaze.
- الخطة المجانية (Spark) تكفي: الشاشة ترسل نبضة كل 5 دقائق وتقرأ البوستات مرة ثم تستقبل التغييرات فقط.
- حالة الشاشة (متصلة/لا) في الأدمن تعتمد على آخر نبضة.
- الفوتر (رقم خدمة العملاء، الساعات، النص) والـQR تتعدل من تبويب **الفوتر والإعدادات**.
